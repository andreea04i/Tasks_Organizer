# Tasks Organizer

## Overview

**Tasks Organizer** is a Java application designed to help users organize and manage their daily tasks through a simple and intuitive interface. The application provides task management functionality, allowing users to keep their activities organized and maintain an overview of their tasks.

## Features

- **Task Management:** Organize and manage tasks in one place.
- **Database Integration:** Uses SQLite for data storage.
- **Search Functionality:** Includes a search feature to help locate tasks.
- **Task Editing:** Provides an interface element for editing tasks.
- **Task Deletion:** Includes functionality for removing tasks.
- **User Interface:** Uses dedicated graphical controls for common task management operations.

## Technologies Used

- **Java** — application logic and functionality.
- **SQLite** — database management and data persistence.
- **JDBC** — database connectivity.
- **Maven** — project and dependency management.

## Project Structure

The project contains the Java source code, the SQLite database, graphical interface resources, and the Maven configuration.

## Purpose

The project focuses on applying object-oriented programming principles, graphical user interface development, and database integration to create a practical task management application.
